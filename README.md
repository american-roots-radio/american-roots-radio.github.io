# American Roots Radio Hub 🇺🇸📻

A clean, ad-free web radio player for **Country, Blues and Gospel** — built to make verified live streams easy to browse and play from one place.

## Live Radio Collection
- 🤠 **124 Country stations**
- 🎸 **52 Blues stations**
- ⛪ **52 Gospel stations**
- ✅ **228 verified live streams**

## Features
- Built-in 10-band audio equalizer
- Favorites and listening history
- Genre filters, search and random station selection
- Persistent bottom player with Play, Pause, Stop and Sleep Timer
- Responsive layout for desktop and mobile
- Installable web app (PWA)
- 100% free and ad-free
